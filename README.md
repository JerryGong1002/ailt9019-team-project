# Spending Analyzer · 消费手记

按 `Project/AILT9019_Project_Proposal_draft_Group_9.pdf` 的最新方案实现的本地网页原型。

## 打开

直接打开 `dist/index.html`，或在本目录运行：

```powershell
python -m http.server 9019 --bind 127.0.0.1 --directory dist
```

访问 http://127.0.0.1:9019 。不需要安装前端依赖。使用同一浏览器和地址访问，以读取同一个本地账本。

## 已完成

- HKD 键盘记账、12 个大类、56 个可选小类、金额校验；支持今天／昨天，Enter 保存、Alt + 1–6 选择分类。
- 总支出、日均支出、分类占比、支出趋势；近 7 天、近 30 天及全部时间筛选。
- 按日期分组的消费记录、每日小计、滚动查看、删除及 12 秒内撤销。
- 个人账本保存在当前浏览器 localStorage；独立示例账本包含两周的合成数据，示例修改刷新后重置。
- 响应式账本界面；辅助文字至少 12px，说明支持悬停与键盘聚焦。
- 右上角支持 English／简体中文／繁體中文，涵盖界面、图表、校验与悬停说明；记住语言选择，切换不改变账本或当前输入。
- 纯白／夜间黑外观，以蓝色强调；首次跟随系统配色，右上角切换后记住手动选择。

主面板保留餐饮、交通、购物、生活、娱乐和「其他」入口；点击「其他」展开更多分类，选中后第六格显示该分类的图标和名称。小类可选，旧记录保持兼容，概览按大类汇总。

## 统计约定

近 7 天是当前本地自然日及之前 6 天（包含边界）；未来日期不计入统计。日均支出以整个所选区间为分母。全部时间从首笔记录到今天。金额存为整数港分，显示时转为 HKD，避免浮点加法误差。超过 30 天的趋势按连续日期桶显示每组日均；橙色横向虚线表示所选区间日均支出（含无消费日期）。

## 后续 API 接口位置

`dist/app.js` 中 `statistics(entries, '7')` 可生成周报所需汇总。接入时由服务端调用 agent API，密钥仅存在服务端；发送白名单字段 `currency`、`start`、`end`、`total`、`average`、`count` 和各分类汇总，不发送 `rows`、记录 ID 或逐笔数据。保留空周和 API 失败状态，数值及图表不依赖 API。

## 设置与备注

左上角设置入口可调整语言和深浅外观。分类列表支持拖动排序（也可聚焦拖动按钮后按上下方向键）；前五个已启用分类展示在首页，其余从「其他」展开。取消勾选会隐藏记账入口，历史记录与统计不变，至少保留一个分类。分类偏好保存在当前浏览器。

每笔支出可填写最多 50 字符的备注，保存后显示在记录中。备注仅本地保存，不进入周报汇总数据。

## 界面调整

顶栏将设置、标题与账本切换水平对齐；历史账单入口切换到全部时间并定位记录。记录提前至概览数字下方。大类采用更大的圆形按钮和灰色圆角分组；分类设置使用圆角卡片，拖动跟手并为相邻项目和松手归位提供动画，尊重减少动态效果设置。

## 当月概览与更多统计

首页总支出、日均和主要消费固定使用当月 1 日至今天，不随记录区筛选变化。右侧更多统计弹窗显示当年 1 月 1 日至今天的累计支出，并支持自定义起止日期（包含首尾，不允许未来日期）。区间指标包括总额、按所有自然日计算的日均、笔数、平均每笔、最大单笔、有消费天数和分类金额/占比。金额仍按整数港分计算；统计仅使用当前账本。

## 历史账单日历与编辑

点击「历史账单」打开月历，支持上／下月、年月跳转、回今天和方向键选择日期。点击任意日期查看明细并补录；记录列表及日历明细均可编辑金额、日期、分类、小类和备注。编辑保留记录 ID 和创建时间，删除支持 12 秒撤销。未保存的日历表单退出时会提示。

月历按当前月份最高单日金额分为四档蓝色（25%／50%／75%／100%），无记录不着色。不同月份颜色不能直接比较。未来日期以「预」标记，其记录参与月历颜色和提前记账汇总，但在日期到来前不进入实际支出统计；本地午夜或重新聚焦页面会刷新。首页支持今天／昨天／自选日期。

实现为 `dist/calendar.js` 与现有账本共享本地存储，无新增依赖或数据迁移。支持简体中文、繁體中文、English，以及浅色／深色和手机布局。

## 手机首页与计算器（2026-10-12）

- 手机首页（720px 及以下）显示今日总消费、近七日迷你折线图和日均虚线；日均包含没有消费的日期。下方仅显示今日记录，列表内部滚动，编辑、删除和撤销继续可用。
- 中间横栏直接打开历史账单、更多统计、消费概览（含周报）和设置。弹窗使用深灰遮罩，内容内部滚动，支持 Escape、关闭按钮和点击背景关闭。日历仍保留未保存编辑的退出确认。
- 蓝底白字的药丸形「开始记账」按钮打开底部圆角面板。顶部金额与保存按钮保持可见，中间六个分类卡、可横滑的小类、四列计算器和可展开的日期／备注区域独立滚动。关闭再打开保留尚未保存的输入。
- 手机与电脑共用计算器：加减乘除、乘除优先、清零、退格和等号；算式为浅灰小字，实时结果为蓝色常规字重。支持键盘数字、运算符、Backspace、Delete 清零和 Enter 保存，也可粘贴完整算式。
- 运算采用精确分数，中间步骤不四舍五入，最终结果才保留两位小数；例如 `10 / 3 * 3` 为 `10.00`。除零、未完成算式、超出金额范围及非正数无法入账。
- 无新增运行依赖、外部字体、图片或图表库。七日图使用内联 SVG；手机上的详细图表和日历按需绘制，日期刷新由下一次午夜定时器及页面重新可见触发，替代逐秒轮询。

新增 `dist/calculator.js`；验证命令仍为 `node --test tests/*.test.cjs`，其中包含计算优先级、小数精度、异常输入和按键状态测试。项目继续使用当前浏览器的本地账本，未新增服务端或跨设备数据同步。

## 月预算

首页预算卡片显示当月剩余额度、已用金额和使用进度，点击打开设置与详情。支持 English、简体中文和繁體中文、深浅主题及手机布局。

- 首次设置默认用于本月及以后；修改可选择「仅本月」或「本月及以后」。每月沿用适用额度，不结转结余或超支，历史月份配置保留。
- 仅统计本月 1 日至今天的实际支出，未来记录到日期当天计入。增删改、撤销及跨日刷新都会更新预算。
- 使用达到 80% 提示接近预算，100% 显示用完，超过后显示超支金额；不阻止记账。详情中的剩余天数包含今天。
- 关闭设置放弃未保存修改；保存失败保留输入。跨月时保留输入并要求重新打开设置，避免误存到新月份。
- 「停用预算」从本月起生效；重新启用需设置金额。当前版本只管理当月预算，不提供历史预算页面。
- 个人预算独立存于 `spending-analyzer.budget.v1`，以整数港分保存。示例预算为 HK$3,000，修改刷新后重置，不影响个人账本。无法读取的预算数据不会自动覆盖。

`dist/budget.js` 提供预算解析、变更和统计函数，并负责预算界面；不新增运行依赖或网络请求。`node --test tests/*.test.cjs` 包含预算继承、当月覆盖、停用、跨年、闰月、未来消费、提示阈值及损坏数据校验。
