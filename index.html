Spendly

Track everyday purchases in Hong Kong dollars and see where your money went this week. Your ledger stays in the browser.

Open the expense trackerView source on GitHub

Try a purchase

Enter 10 / 3 * 3 on the calculator, choose a category and save. Look for a new HKD 10.00 entry in today’s records, then open the calendar to see it on today’s date. The calculator keeps exact fractions until the final amount is rounded to cents.

From entries to a weekly review

The tracker groups purchases by date and category. Future entries appear in the calendar and join actual spending totals when their date arrives. For an AI review, the local app compares two adjacent seven-day periods. It sends aggregate figures through the backend to the model, keeping individual entries and notes in the browser.

Run locally

Download or clone the repository and open dist/index.html to use the ledger. For AI reviews, follow the README to configure a private provider key in the server’s .env file. Run node --env-file=.env server/server.cjs from the repository root, then open http://127.0.0.1:9019. With a recorded expense and working provider access, generating a review returns a short English summary. The hosted demo runs the browser features only.
