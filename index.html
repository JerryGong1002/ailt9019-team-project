1. Users, Problem & Scope

Spendly is designed for people who record everyday purchases in Hong Kong dollars and want a direct, verifiable answer to a practical question: where did my money go this week? Entering an amount and category immediately updates the ledger, calendar heatmap, trend charts, and monthly budget bar without requiring an account or cloud database.

In Scope

  • Offline-first HKD expense entry across 12 main categories and 56 optional subcategories, with inline editing and 12-second delete undo.
  • Instant ledger history, inline SVG trend and category charts, Monday-first calendar heatmap with future-dated entries, and monthly budget tracking (80% warning and 100% threshold).
  • On-demand plain-English weekly review comparing two adjacent 7-day periods using either a user-supplied browser API key (Gemini, OpenAI, Claude, DeepSeek, OpenRouter, or Custom Base URL) or a local/hosted Node.js backend, with a customizable global prompt in Settings.

Explicitly Out of Scope (“Does Not”)

  • Does not provide financial, investment, credit, or debt-management advice, or instructions to execute transactions.
  • Does not connect to bank accounts, infer purchasing motives, or synchronize ledgers across devices.
  • Historical budget browsing and persistent AI report history remain outside the delivered scope.

2. Workflow & Domain Customisation

All monetary arithmetic, calendar boundaries, schema validation, and week-over-week comparisons are performed deterministically by team-written code before any language model is called. The model supplies concise natural-language phrasing only.

Step 01 · Input

Exact Entry

Enter an HKD amount or arithmetic expression (e.g. 10 / 3 * 3), choose a category, date (past, today, or future), and optional 50-character note.

Step 02 · Processing

Deterministic Aggregation

Exact rational arithmetic rounds once to integer HKD cents. Future entries appear in the calendar without inflating actual spending until due. Weekly reviews validate two adjacent 7-day periods and precompute shares and deltas (omitting % when the prior total is 0).

Step 03 · Output

Ledger & Weekly Review

Updates summaries, charts, and monthly budget immediately. When requested, the active global prompt (editable in Settings) and aggregate JSON produce a neutral 3–5 sentence English paragraph.

3. Genuine Run Example

Both walkthroughs below can be reproduced directly in the live interactive demo, watched in the official demo video, or verified from a fresh local clone.

A. Exact-Fraction Entry Check

In Personal or Demo mode, enter 10 / 3 * 3 on the calculator keypad, select Food, and save.

Observed result: Evaluated as an exact fraction and stored as 1000 integer HKD cents, displaying HK$10.00 (preventing floating-point 9.99 drift) and immediately updating today’s record group, monthly total, and calendar cell.

B. Two-Week Synthetic Demo Ledger

Switch to the built-in Demo ledger (16 synthetic entries across 14 days, separate HK$3,000 demo budget) and expand Inspect the summary sent for AI reporting:

  • Current 7 days: HK$854.00 (12 entries; largest single expense HK$249.00)
  • Previous 7 days: HK$355.00 (4 entries; max HK$189.00) → +HK$499.00 (+140.6%)
  • Top categories: Food HK$289.00 (33.8%, +416.1%), Shopping HK$249.00 (29.2%, +31.7%), Living HK$128.00 (15.0%)

4. Evaluation Results, Failure Cases & Limitations

Running node --test tests/*.test.cjs executes 48 automated tests across 6 suites (all 48 passing, zero external test dependencies), verifying numerical precision, calendar/budget boundaries, aggregate schema validation, prompt parity, multi-provider routing, and failure recovery.

Test Suite Result Coverage
tests/calculator.test.cjs 5 / 5 pass Operator precedence, exact fractions, half-cent rounding, division-by-zero and invalid-input rejection.
tests/calendar.test.cjs 4 / 4 pass Leap years, Monday-first grid offsets, future-dated entry separation, intensity levels, non-mutating edits.
tests/budget.test.cjs 4 / 4 pass Monthly inheritance without balance rollover, month-only overrides, 80%/100% thresholds, malformed storage guard.
tests/statistics.test.cjs 8 / 8 pass Integer cents, inclusive 7-day windows, synthetic data total conservation, subcategories, custom date ranges.
tests/report.test.cjs 11 / 11 pass Aggregate schema validation, prompt parity with weekly-report-prompt.txt, { summary, prompt } override, CORS, concurrency & hourly rate caps, secret redaction.
tests/report-ui.test.cjs 16 / 16 pass Empty-week 0-network fallback, ledger-switch & key-clear abort races, 5 provider presets + Custom Base URL, memory-only key & error redaction, Settings prompt persistence & reset.

Observed Failure & Boundary Cases

Case Expected / Safeguard Observed Behaviour & Mitigation
Unsupported LLM Attribution
(Midterm live check)		 Model must not assign a category to maximum because category is omitted from the payload. An earlier live response attributed the HK$249.00 largest expense to Shopping solely because Shopping’s category total also equaled HK$249.00. Added an explicit anti-attribution rule to weekly-report-prompt.txt (enforced by automated parity test) and surfaced the inspectable JSON summary in the UI.
Empty Current Week
(Boundary case)		 Return exact fixed fallback locally with 0 API calls. Verified in unit and browser checks: displays “No expenses were recorded for this seven-day period.” with zero network requests even when an API key is entered.
Ledger Switch / Key Clear Mid-Request
(Race condition)		 Delayed reply from a previous ledger or cleared key must never overwrite current state. Version tokens and AbortController cancel in-flight requests and discard stale responses; Generate remains immediately usable afterward.
Invalid Input, Unsafe URLs & Provider Errors
(Robustness)		 Block bad inputs before saving/calling; sanitize all errors. Division by zero, non-HTTPS/credentialed custom URLs, contradictory summaries, HTTP 401/403/404/429, CORS failures, and truncated/markdown model replies show actionable inline messages with API keys scrubbed.

Known Limitations & Ethics / Privacy

  • Prose verification: Automated tests confirm deterministic arithmetic, payload validation, and error handling—not the live factual-accuracy rate of third-party LLM prose. Users should verify reported figures against the visible summary.
  • Privacy boundary: Personal records stay in origin-scoped browser localStorage and API keys stay in memory only, but user-initiated AI reviews still send aggregate seven-day spending patterns to the selected API provider.
  • Recording bias: An incomplete ledger can make changes in recording habits look like changes in real spending; the default prompt restricts claims to recorded expenses and forbids inferring motives or giving financial advice.
  • Browser CORS constraints: Direct browser calls depend on the selected provider’s CORS policy (verified on Google’s Gemini API for this origin; providers that restrict browser CORS can still be accessed via the local Node server).

5. Run Instructions & Reproducibility

Option A · Online GitHub Pages Demo

Open jerrygong1002.github.io/ailt9019-team-project/demo/.

  • Expense entry, calculator, calendar heatmap, SVG charts, and monthly budgets run immediately in the browser with no setup.
  • For live AI weekly reviews, choose Gemini, OpenAI, Claude, DeepSeek, OpenRouter, or Custom Base URL and paste your own API key (memory-only; clears on reload or via Clear).
  • Open Settings to inspect, customize, or reset the initial global weekly-report prompt (saved in browser localStorage).

Option B · Fresh Clone, Tests & Local Server

Requires Node.js ≥ 22 with zero npm packages.

git clone https://github.com/JerryGong1002/ailt9019-team-project.git
cd ailt9019-team-project
node --test tests/*.test.cjs

# Offline ledger only: open dist/index.html
# Full local server (copy .env.example to .env first):
node --env-file=.env server/server.cjs

Open the local URL printed by the server (default http://127.0.0.1:9019). Leaving the browser API key empty routes requests through the local server using your private .env credentials.
